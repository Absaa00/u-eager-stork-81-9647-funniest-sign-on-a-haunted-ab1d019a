# Funniest Sign on a Haunted Server Room Door

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

Entry for the [make.fun](https://make.fun) bounty
"Funniest Sign on a Haunted Server Room Door".

## The line

> WARNING: Haunted. Do not unplug anything - the ghost is load-bearing. It holds the RAID array together.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt`. Deterministic, no network,
no dependencies.
